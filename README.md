# Estud-IA Nube · Intermedio

Materiales de clase: diapositivas y ejercicios de cada encuentro.

**Abre la página del curso:** https://santiagohenao97.github.io/estudia-nube/

Un proyecto tuyo, 10 encuentros, una sola pregunta: ¿cómo logro que un servicio se pueda repetir, cambiar, recuperar y vigilar, y cómo lo demuestro?
